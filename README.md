# ISLA CENIZA

ISLA CENIZA is an original open-world crime game set on a volcanic tropical island. Explore on foot and by car through traffic and crowds of pedestrians, steal any car, and outrun a five-star wanted system while police units chase you across the island. Seven story missions lead from a battered harbor pier to a volcano-side climax, with combat, a HUD and minimap, a day-night cycle, and save/load support.

## Controls

- **WASD** move
- **Mouse** orbit camera
- **E** enter/exit car
- **Shift** run
- **Mouse click** shoot
- **Esc** pause
- **M** map
- **R** radio

## Run locally

Run `node serve.ts`, then open <http://localhost:8080>.
